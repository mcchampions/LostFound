# 运维

## 日志

- 控制台 + 文件双输出；文件位于 `<home>/logs/`（jar 模式即
  `backend/app/logs/`）；
- 文件名：`日期-第几次启动.log`（如 `2026-08-02-1.log`），每次启动一个文件；
- 默认级别：业务包 `info`，SQL 日志 `off`（本地调试可 `LOG_LEVEL_SQL=debug`）。

## 数据库迁移

- 启动时自动执行未记录脚本，记录于 `schema_migration`；
- 任一脚本执行失败会抛出异常并**拒绝启动**，请检查启动日志中的
  `DatabaseInitializer` 错误，修复后重新启动；
- 重跑脚本：删除 `schema_migration` 对应记录后重启。

## 定时任务

| 任务 | 周期 | 说明 |
|---|---|---|
| 离线未读摘要邮件 | 3 分钟 | 每轮离线仅提醒一次 |
| 已提醒状态清空 | 24 小时 | 允许再次提醒 |
| 图片按龄压缩 | 每天 03:30 | ≥7 天 720P，≥30 天 540P |
| 操作日志清理 | 每天 04:00 | 超过 `LOG_RETENTION_DAYS`（默认 365）删除 |
| 邮件重试 | 5 分钟 | 退避重试，超限放弃 |
| 防爆破/限流记录清理 | 1 小时 | 防内存残留 |

## 图片生命周期

| 时机 | 动作 |
|---|---|
| 上传 | 最长边压缩到 1080P |
| 超过 7 天 | 720P |
| 超过 30 天 | 540P |
| 物品标记已解决 | 立即 540P |
| 物品软删除（回收站） | 保留文件与数据，恢复后原样可用 |
| 物品彻底删除 / 图片被替换 | 同步删除文件，并清理无引用的 `media_file` 记录 |

## 回收站

- 失物/招领删除为软删除（`deleted_at` 非空），列表/详情/认领/统计/导出均
  排除回收站数据；管理端可恢复或彻底删除（存在申请记录时禁止彻底删除）；
- 用户软删除后不可登录、不可被搜索，管理端可恢复；
- 管理员相关操作（删除/恢复/彻底删除）均写入操作日志。

## 内存状态说明（单机）

- 离线邮件跟踪、在线状态、登录防爆破、封面限流、邮件重试队列均为进程内存；
- 应用重启后状态清空（离线未读会重新收集，可接受）；
- 多实例部署需迁移到 Redis 并加锁。

## 常见排障

- 时间功能报错：确认迁移 `migration_time_range.sql` 已执行（`lost_time_end` 列
  存在）；
- 封面生成失败：确认 postgen 服务可达（`POSTGEN_BASE_URL`）且
  `POSTGEN_ENABLED=true`；
- 邮件未收到：检查 SMTP 配置、邮箱验证状态、`user_email_preference` 偏好开关、
  `logs/` 中的重试与失败日志；
- 登录被锁：等待锁定到期（默认 15 分钟）或重启（内存态清空）。
- 时间类功能异常：确认服务器时区或 `-Dapp.timezone` 与数据库
  `serverTimezone` 一致（默认 Asia/Shanghai）。
